# Changelog

All notable repository and benchmark changes are recorded here. Historical release data must not be overwritten.

## [1.0.0] - 2026-08-04

### Added

- Frozen dataset from 60 randomized cold loads performed on 31 July 2026.
- Four architecture variants: control, web GTM-style, sGTM proxy-only, and sGTM consolidated.
- Raw JSON, processed JSON, and compact CSV results.
- Portable Playwright runner with environment and run manifests for future executions.
- JSON Schemas, integrity checks, automated tests, Docker support, and GitHub Actions workflows.
- Evidence matrix separating measured results from documentation-based and architectural conclusions.
- Dated filter-list audit with an explicit snapshot-provenance limitation.
- Citation, licensing, repository setup, release, and article-linking documentation.

# Data statement

## Dataset type

The `v1.0.0` dataset is synthetic benchmark output. It contains browser timing, request, transfer, and logical-delivery measurements produced against a local test server.

## Personal data

The dataset is not intended to contain personal data. Run identifiers are randomly generated technical IDs used only to associate local requests with a benchmark run. They do not identify people, devices, customers, accounts, or production sessions.

## External systems

The benchmark does not send events to live Google Analytics, Google Ads, Meta, affiliate, CRM, payment, or other production vendor endpoints.

## Prohibited additions

Do not commit real cookies, click identifiers, advertising IDs, user IDs, customer IDs, order data, IP logs, service-account files, secrets, customer hostnames, or production request payloads.

## Provenance

The frozen data was imported from the original Metricfixer benchmark package. File-level hashes and the original source-archive hash are recorded in `data/manifest/benchmark-manifest.json` and `data/checksums/SHA256SUMS.txt`.
